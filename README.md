# Portfolio profesional — Jeison Andrés Patiño González

Portfolio web personal para presentar mi trayectoria profesional, formación académica y evolución hacia el desarrollo de software, análisis de datos, automatización e inteligencia artificial.

## Vista general

El proyecto comenzó como una actividad académica de implementación de HTML5 y evolucionó hacia un portfolio profesional. La base utiliza HTML5 semántico y CSS3, con énfasis en accesibilidad, responsive design y una estructura preparada para incorporar nuevos proyectos.

## Perfil

Soy Supervisor de Operaciones con experiencia en la industria BPO y estudiante de Ingeniería de Software. Mi perfil combina liderazgo de equipos, gestión de operaciones y análisis de indicadores con una formación técnica orientada a Python, SQL, desarrollo web, datos e inteligencia artificial.

## Accesibilidad

La implementación considera buenas prácticas básicas de accesibilidad:

- `lang="es"` para identificar el idioma principal.
- Elementos semánticos como `header`, `nav`, `main`, `section`, `article`, `aside` y `footer`.
- Etiquetas `label` asociadas correctamente con los controles del formulario.
- Atributos `alt` en imágenes.
- `aria-label` para identificar la navegación principal.
- Navegación mediante teclado.
- Indicadores visibles de foco con `:focus-visible`.
- Enlace para saltar al contenido principal.
- Contraste visual considerado en la interfaz.
- Respeto por la preferencia del usuario de reducir animaciones.
